# 1k／10k 已训练代码与完整模型结构复核

核验日期：2026-09-15。结论：**针对用户明确列出的主模型前向链路，当前已完成的 1k 和 10k MTO 实验满足要求：完整保留该链路，仅以光谱作为数据监督目标。**

元素与几何 → DetaNet → 状态条件化 MTO → 参考／目标 CG 关系 → 逐态激发能与跃迁强度张量 → 振子强度 → 可微展宽 → 光谱。

标量头使用 Inv(M0)、Inv(Ma)、CG 的 0e 关系，张量头使用 CG 的 2e 关系和合法门控的 Ma(2e)。这是规划允许的读出结构；所有这些特征都经过 MTO。不存在绕过 E/A/f 和展宽的 601 维直接光谱 MLP 输出。

E、A、f 模块在正式训练的 forward 中实际使用，并非只在 export 时计算。export 额外提供它们和原子装配项以便复核。未引入 E/A/f 的标签损失、轨道损失或 rank penalty。AdamW 的 weight decay 属于优化器正则化，不是额外的物理量标签监督。

## 结构确认的边界

这里确认的是用户列出的 **MTO 主模型链路**。实验中的 DetaNet 对照使用池化及相同的物理解码形式，按对照定义不含 MTO 装配和参考 CG。其他规划消融不包含在本次两个主分支的实验中。

仅各向同性光谱监督不能唯一辨认候选态分解、MTO 的物理意义或 A 的方向。因此“完整结构已经训练”不等于“逐态激发能和跃迁张量已经获得独立物理精度验证”。10 个目标态是候选分量，M0 是学习的参考因子，不解释为真实基态波函数。

光谱网格采用当前数据的 601 点，σ=0.2 eV 为模型约定。原论文使用过另一展宽设置；本次源 CSV 的实际生成宽度及绝对强度标度尚未逐项复现，不能从本次结构核验推出这些数据约定也已全部验证。

## Conservative molecular components

1. Validate one-to-one ID/order alignment, finite coordinates, integer allowed atomic numbers and atom counts, without inspecting targets. Preserve every valid-corpus row. A malformed identity/geometry stops preparation; no silent dropping.
2. Compute full elemental formula from actual atomic numbers. Parse each cached explicit-H connectivity key without removing H or sanitizing/reinferring bond orders. Check its atom-element counts against the geometry. A parse/count/connectedness failure marks the row ambiguous.
3. Build a canonical heavy-atom graph with atomic number as node label, all existing heavy-heavy edges single, zero formal charges, no stereochemical/aromatic/isotope annotation, and no implicit H. Combine its canonical graph string with the complete formula. This intentionally groups bond-order/stereo variants and tautomeric H allocations with the same formula/heavy connectivity; it is a conservative chemical family, not a claim of exact molecular identity. Preserve original full-key groups through union as well. All conformers sharing this rule remain together.
4. For every previously unresolved row, and any newly detected cached-key parse/composition/connectivity/isotope/charge ambiguity, generate additional connectivity candidates using the original declared van-der-Waals factors `(1.2,1.15,1.1,1.25,1.3)` with neutral charge assumptions. Generate the same heavy-graph/formula keys and union with every matching row, without choosing a factor using labels. All components touching an unresolved/ambiguous row are TRAIN-only. This propagates uncertainty to linked resolved rows instead of assuming unresolved rows cannot overlap. Candidate-generation failures keep the row ambiguous and retain every successfully generated candidate link; they never remove a row or a previously known link.
5. Add a geometric safeguard within each full-formula bucket: sort interatomic distances separately for each unordered element-pair type, concatenate in lexicographic pair order, and compare these vectors in FP64. Union every pair at L-infinity distance at most `1e-4 Å`, using an exact radius query (`eps=0`) and a direct FP64 bound check. This catches numerically congruent geometries independent of rotation/reflection/atom permutation, including differently inferred graphs. Homometric structures can share this descriptor, so matches are conservative unions, not an isomorphism proof. It does not identify arbitrary conformers; graph grouping handles those. No geometry-distance threshold search is allowed.
6. Use a deterministic union-find whose representative is the smallest original row index. Iterate candidate edges in sorted row-index order. Compare complete canonical keys, not hashes, when constructing graph groups. Use SHA256 only for provenance; if two unequal full signatures share a hash, stop and retain both private records for review. Components are identified by their sorted member-ID sequence and ordered by their minimum molecule ID (which is unique). No component can be split.

Bond perception and finite-precision geometry remain limitations. The enforceable claim is zero partition overlap under these audited identity/component rules. It is not absolute proof that all chemical identities are resolved. Record every ambiguity class, number of affected components/rows, largest component and conservatively merged group counts. Do not silently relax grouping to achieve an exact fraction.

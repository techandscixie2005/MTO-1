# Builder contract and allowed access

The fixed seed, grouping factors, 1e-4 Å geometry threshold and whole-component assignment are unchanged from NEW_PARTITION_PROTOCOL.md. Newly discovered cached-key parse/composition/connectivity/isotope/charge ambiguities also receive all five connectivity candidates, conservatively extending the unresolved-row safeguard. Every resulting linked component remains TRAIN-only. No candidate or factor is selected using outcomes. H-only graphs use a fixed empty-heavy sentinel plus their full elemental formula.

The only decoded members of the curated dataset ZIP are `ids.npy`, `z.npy` and `pos.npy`; IdentityArchive rejects every other member before opening the archive. Pinned old split/identity JSON and old internal-fit/calibration index arrays are read solely for identity and exposure counts. Files may be hashed as opaque bytes. No target, target mask, prediction, model, or checkpoint is decoded.

`freeze` seals code/protocol/settings/environment hashes. `synthetic_split_checks.py` runs on invented molecules and temporary synthetic files only. `audit` requires a hash-bound independent PRE_CORPUS_REVIEW.json and writes aggregate CORPUS_AUDIT.json, without private split arrays. `materialize` additionally requires a hash-bound MATERIALIZATION_REVIEW.json approving that exact corpus receipt. It rebuilds and compares the entire deterministic aggregate result, then writes private arrays/signatures with immutable byte checks. Identical re-runs retain existing files; disagreement stops without overwriting.

The independent pre-corpus review JSON has passed=true, phase=pre_corpus, source_manifest_sha256, and synthetic_checks_sha256. The materialization review has passed=true, phase=materialization, source_manifest_sha256 and corpus_audit_sha256. A later independent disjointness verifier should inspect saved partition arrays and reconstruct identity links using allowed identity/geometry only, without target statistics or scoring. No training is authorized by a builder review.

All arrays, molecule memberships, identifiers and canonical signatures stay in the server-only private_partition directory. Only source, configuration, hashes, aggregate counts, review records and exposure matrices may be archived. The geometry descriptor is a conservative union safeguard, not a proof of chemical identity. Test is a new partition of historically used rows, not an external or retrospectively untouched dataset.

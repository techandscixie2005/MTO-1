# MTO bottleneck audit: distinguish a missing path from an accuracy cause

Read-only audit after Round07 publication `703c2cd7c68f4068160ab9d3dbbab64d4d5af6ba`. Scope: source text and already published aggregate records only. No dataset target, private prediction array, checkpoint tensor, model instance, numerical experiment or optimizer update was used. Completed records are unchanged. The retained v2 validation reference is Round05 control45, R² **.44716940136585204**; the .60 objective remains unmet and TEST remains sealed.

## Finding and recommendation

The original backbone has no explicit edge path carrying an atom's existing equivariant tensor features to another atom. Its edge message takes scalar features, radial features and bond harmonics. Existing tensors are accumulated and transformed at each atom; their contractions influence later scalar features. This is a source-proven computational restriction, **not** a proof of lost target information, insufficient universal expressivity or the cause of the observed errors.

Recommend one upstream question: **does explicitly transporting existing tensor features between atoms improve generalization beyond an equally parameterized local tensor residual and the unchanged model?** Keep MTO pooling, reference-state CG coupling, PSD decoder and original LE+Ls unchanged. `TRANSPORT_PROPOSAL.md` gives a fixed three-arm contrast for root consideration. No implementation or execution is authorized by this audit.

## Limits and decision

The backbone may already encode the needed neighbor orientation into invariant S sufficiently; explicit transport may be redundant or worsen generalization. Conversely, extra residual capacity alone may help. The original/local/neighbor contrast distinguishes those recipe-level outcomes without claiming a quantum operator. It does not prove information-theoretic insufficiency of the original model, and a negative result would close only this bounded transport choice.

The upcoming proposal remains geometry-only, one model/checkpoint. It uses no MO/X/Y/density labels and does not revisit the symmetry-invalid ordinary polar-vector construction.

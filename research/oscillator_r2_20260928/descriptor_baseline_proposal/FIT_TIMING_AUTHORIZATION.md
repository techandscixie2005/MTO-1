# Conditional full-fit timing authorization

The root research coordinator approved one bounded descriptor fit/evaluation after the completed native scratch arm showed severe train-to-validation overfit. The descriptor probe supplies independent feature information alongside the fixed five-model validation candidate. This approval lifts the earlier scheduling condition that both scratch and seed families complete first; it does not change the scientific protocol or allow a parameter search.

Execution remains conditional on exact-hash independent implementation review PASS, fresh CPU/memory admission, and a timestamped `FIT_AUTHORIZATION.json` bound to the final reviewed sources, frozen protocol and preflight. The single run uses the fixed 803-feature schema; one ExtraTrees fit with 256 trees, depth 24, minimum leaf 4, sqrt feature sampling, random state 20260929, and eight workers. Total envelope is 16 GiB process address space and four hours wall time. Train-only fit and coefficient/model freeze precede any validation access. Validation compares the standalone forest and exact 0.5 descriptor + 0.5 F5 mean only. No test access, retuning, extension or extra fit is authorized. Resource failure is `INCOMPLETE_RESOURCE`, not a scientific score.

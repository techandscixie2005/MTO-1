# Conditional descriptor baseline: one bounded nonlinear probe

Recorded at: 2026-09-29T06:42:15.852398+08:00

**Design only. No feature implementation, fitting, inference, validation evaluation, or launch is authorized.** Completed seed/scratch reviews take priority and determine whether this proposal proceeds. Interim scores are not final results and do not change either active protocol.

## Question and one candidate

Can a fixed nonlinear learner over explicit composition, geometric connectivity and rotation-invariant shape/distance summaries provide useful native-f information complementary to frozen F5? Use one native multioutput `sklearn.ensemble.ExtraTreesRegressor`, jointly predicting S1..S10 raw oscillator strengths. Evaluate only its standalone prediction D and the prespecified equal blend `(D + F5)/2`; no weights, subsets, extra target transformations or learner search. F5 is the already frozen five-component predictor pinned by the fixed-seven provenance, not a newly selected reference.

This is distinct from the negative linear frozen-Gram probe: its features do not depend on the neural checkpoint, and its predictor is nonlinear. Failure would constrain this descriptor/learner/budget combination, not nonlinear invariant representations, backbones, or coupled-state models generally.

## Input provenance and honest graph fallback

Read-only executor feasibility found scikit-learn 1.7.2 and RDKit 2025.09.4 installed. The neural dataset provides atomic numbers, coordinates and geometric edges at 5 Å. It does not persist authoritative bond-typed SMILES/bond orders. Identity keys describe connectivity before successful bond-order assignment; they must not be treated as chemically typed SMILES. The existing validity procedure had 278 unresolved TRAIN rows; none may be removed.

Use the same uniform fallback for **every** molecule: a bond-agnostic geometric graph built solely from nonpadding Z and Cartesian coordinates. An undirected edge exists for distinct atoms when `distance <= 1.3*(r_i+r_j)`; fixed radii in Å are H 0.31, C 0.76, N 0.71, O 0.66, F 0.57. These numbers are frozen preprocessing constants, not learned bonds. Explicit H atoms are retained. No valence sanitization, inferred bond orders, aromatic flags, SMILES identity, data-validity flags, target-derived quantum quantities, true E, tensor labels or transition dipoles enter features. Unsupported elements/nonfinite input stop the implementation review instead of filtering rows.

This graph adds a chemical-scale preprocessing assumption to the same Z+coordinate information available to the neural backbone; it does not add authoritative chemical labels. If future work instead uses externally supplied bonds/aromaticity, it would be a distinct information-enriched study. Do not silently switch representations after seeing outcomes.

## Fixed feature schema: 803 columns

- **Composition 7:** counts of H/C/N/O/F, total atoms, heavy atoms.
- **Connectivity 535:** 512 hashed atom-neighborhood count bins; 15 unordered element-pair edge counts; 6 degree counts for 0/1/2/3/4/5+; number of connected components; cycle rank `edges-atoms+components`. Exact neighborhood serialization: let L0(i) be the base-10 atomic-number string. For r=1,2 simultaneously set Lr(i)=hex SHA-256 of UTF-8 JSON [r,L(r-1)(i),sorted neighbor L(r-1) strings], with separators (comma,colon) and no spaces. For each atom and r=0,1,2, increment bin int.from_bytes(SHA-256(UTF-8 JSON [r,Lr(i)]), big-endian) modulo 512. Use full 256-bit hex labels between rounds; only final bins collide. Freeze literal serialization fixtures before fitting. No dictionary is learned across molecules.
- **Distances 255:** for each of 15 unordered element pairs, its number of distinct atom pairs plus 16 mean Gaussian radial responses, centers 0.5,1.0,...,8.0 Å and width 0.5 Å; response `exp(-(d-center)^2/(2*width^2))`. For an absent pair, count and responses are zero. All distances contribute without a learned cutoff.
- **Shape 6:** descending eigenvalues of centered, unweighted covariance `X.T@X/N`, radius of gyration `sqrt(sum(eigenvalues))`, and lambda2/lambda1, lambda3/lambda1. Require minimum eigenvalue >= -1e-12*max(trace(covariance),1), then clip negative eigenvalues to zero; larger negativity fails preflight; if lambda1<=1e-20, both ratios are fixed zero. No orientation-dependent coordinates are features.

Compute geometry in FP64 then store feature columns in fixed-order FP32. No learned feature normalization, imputation, feature selection, target encoding or validation-fitted bins. Use element order H,C,N,O,F and lexicographic unordered pair order; within each distance block place count before ascending centers. For covariance output use descending eigenvalues, radius of gyration, q2, q3. Record TRAIN pairs within 1e-10 Å of a graph threshold as numerical-boundary diagnostics; any failed invariance check requires review, not row removal or an outcome-driven threshold change. Preflight must establish translation/rotation/reflection/permutation invariance on synthetic and fixed TRAIN-only rows, boundary behavior, finite dimensions and preservation of every row. Fingerprint collisions and hard graph thresholds are explicit limitations.

## Learner, objective and budget

Freeze: `n_estimators=256, criterion="squared_error", max_depth=24, min_samples_leaf=4, min_samples_split=2, max_features="sqrt", bootstrap=False, random_state=20260929, n_jobs=8, ccp_alpha=0, min_impurity_decrease=0, warm_start=False`; other parameters explicitly match scikit-learn 1.7.2 defaults. Use all 120,355 fixed training molecules with equal sample weights and all 10 targets. Define one TRAIN-only scale `s = sqrt(mean((f_train - mean(f_train))^2))`, pooled over all transitions; train on `f/s` without centering, then multiply predictions by s. Common scaling preserves the pooled raw-f squared-error objective; do not standardize or weight individual states. Multioutput tree splits average squared-error reduction over outputs. Leaf means preserve nonnegative strengths without a tuned positivity transform.

The tree count and depth are fixed, so no early stopping/inner split is needed: perform one full-TRAIN fit, not ten independently tuned learners or a validation-selected refit. No OOB model selection. If a future implementation insists on stopping, return for a revised pre-outcome protocol with connectivity-group TRAIN-only selection and full-train refit; do not improvise it during this run.

Prefer CPU only after executor resource admission confirms capacity without disrupting existing jobs: cap at 8 tree workers and BLAS/OpenMP threads 1; no GPU needed or reserved. 803 FP32 features require about 0.3866 GB for TRAIN and 0.0215 GB for validation. With leaf minimum 4, total tree nodes are bounded by roughly 15.4 million before the depth limit, so model storage should be several GB rather than hundreds; actual runtime/memory remain unmeasured. Proposed hard envelope: 16 GiB process memory, 4 wall-clock hours including features/fit/evaluation, at most 32 CPU-core-hours of fitting. Abort before validation if the full fit cannot finish within either hard limit; preserve partial artifacts/logs with an INCOMPLETE_RESOURCE receipt, never use them for candidate scores. A cap hit is an incomplete implementation/resource outcome; do not score a partial forest as the scientific negative, extend the budget automatically, or retune after validation. Record peak RSS, elapsed times, node counts and serialized bytes. No library installation is needed according to current feasibility.

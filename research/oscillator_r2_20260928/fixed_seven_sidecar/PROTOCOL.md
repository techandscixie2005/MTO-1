# Fixed-seven saved-array sidecar

This isolated utility implements the already-published [fixed-seven secondary amendment](../postrun_geometry/FIXED_SEVEN_SECONDARY_AMENDMENT.md), SHA-256 675030449886676094b1226d6ea75d753752fdd7e3e7cc3c8e1a9441bb469c0e. It changes no trainer, checkpoint, selection, scratch primary contrast, or existing postrun-geometry output.

## Fixed arithmetic and timing

F5 is the equal native-f mean of the five immutable validation arrays named in the amendment provenance: eta0, eta01, eta1, G1 epoch75, G3 epoch174. Future F7 is exactly (5 F5 + seed23 legacy-joint-selected native f + seed37 legacy-joint-selected native f)/7. Eta0 appears once. The existing seed3 primary is (eta0 + seed23 legacy + seed37 legacy)/3. No raw-f-selected seven-way variant, fitted weights, alternative subset, checkpoint search, model inference, training, or test access is permitted.

The `--fixture` mode uses only the five immutable validation arrays and synthetic seed values. It verifies F5 pooled raw-f R² 0.48769960489832564, round09 q2 population/SSE, arithmetic, and synthetic full-loader success plus missing/FAILED/INVALID/selection/checkpoint/array rejection for both families. The synthetic fixture proves no future family prediction is opened before both FIT_COMPLETE terminals pass. It must not load current seed or scratch run outputs. A future `--seed-completed` mode is allowed only after separate independent exact-hash review and both 100-epoch/188100-update FIT_COMPLETE receipts pass all source/checkpoint/selection/prediction gates. A future `--scratch-supplemental` mode requires both scratch arms complete but does not depend on seeds; it compares F5 with their already prescribed raw-f-selected components and fixed 0.5/0.5 mean, preserving native-minus-MTO as the primary scratch contrast elsewhere.

## Input and output gates

Verify the amendment/provenance and all pinned reference hashes, including five component NPZ hashes. Each completed-family mode requires this sidecar's independent review to bind its exact protocol/code/preflight SHA. Reject missing, FAILED or INVALID terminals; refuse to overwrite any completed output. For seeds, require seed identity 23/37, 100 epochs, 188100 updates, test_batches=0, legacy epoch1..100, the reviewed seed source/code map and its current file hashes, pinned protocol/preflight, FIXED_CHECKPOINT_METRICS hash and legacy epoch, selected checkpoint hash, and val_best_legacy.npz hash from FIT_COMPLETE. For scratch, pin SCRATCH_SOURCE_PINS.json and independently verify the reviewed scratch protocol, preflight and implementation review, its full source/code hash maps against current files and both FIT_COMPLETE receipts, fixed-metrics and selected raw-f epochs, selected checkpoint bytes, and saved prediction hashes before opening arrays. This is a sidecar-only strengthening of the old postrun_geometry gates. No missing artifact triggers replay.

All component arrays must match exact 6686 validation indices, molecule IDs, raw printed FP64 f truth, masks, and ten-state order. Only native f is averaged. Inputs and truth must be finite. The Round09 q2 bins and fixed threshold are TRAIN-derived; q3 remains descriptive. All full metrics retain 6686 molecules and 66860 states. Server-only prediction arrays and checkpoints are excluded from archive.

## Fixed analyses

For F7 against F5 and primary seed3, report pooled FP64 SSE/SST/R²/RMSE/MAE and signed SSE changes. Use 2000 paired molecule and connectivity-group bootstrap draws with seed 20260929 and recomputed pooled SST, retaining all ten states per molecule; the same unit draws are used for the two contrasts. Report physical S1..S10 SSE, below q90=0.0546, q90-and-above and q99-and-above=0.2377 counts/SSE, largest gains/losses by molecule and group, gross gain/deterioration, top ten positive gains, ID14562, the six fixed low-q2 cases, and every frozen q2 bin. Report absolute reference and candidate SSE for the case, six-case, molecule and group concentration records alongside changes. Nonexistent gain/loss extrema are null. Gain shares are null if total gain is nonpositive. Record model inference counts F7=7, F5=5, seed3=3, scratch native=1, scratch MTO=1 and scratch mean=2; counts are not calibrated latency. For scratch supplemental, use the same metrics and paired uncertainty versus F5, without changing the existing primary scratch result.

JSON writing is atomic, UTF-8, with nonfinite values rejected. The Markdown report is UTF-8. Output is exploratory and conditional on repeated validation selection; the fixed-three historical test score does not belong to F5 or F7, and no test is opened.

# Seed saved-array compatibility amendment

The reviewed fixed-seven sidecar expected every selected prediction NPZ to contain `mask_f_true`. The reviewed seed trainer exports `ids`, `indices`, FP64 `f_true`/`E_true`, `f`, `E`, and `A`; it does not export the mask field. The authoritative raw printed validation mask is fully true for all 6,686 molecules and ten states. The first authorized completed-mode call stopped at seed23 array schema validation and produced no fixed-seven result.

This isolated adapter leaves the reviewed fixed-seven sidecar and active/completed training sources unchanged. It invokes its existing completion, source, checkpoint, selection and prediction-hash gates. Only the two exact seed legacy-selected paths may omit `mask_f_true`. For those paths, the adapter requires the frozen reference mask to be Boolean and fully true, exact 6,686 validation IDs/indices and FP64 raw f/E truth, a file hash supplied by the terminal receipt, and finite 10-state predictions. If a mask field is present, it must equal the reference. Every other input uses the original strict loader. The adapter first verifies its own independent exact-hash review and the original sidecar review; it records both source hashes and output hashes in a separate UTF-8 execution receipt.

Preflight uses synthetic rows only and verifies positive loading and failures for changed IDs, FP64 truth, missing/non-all-true reference masks, nonfinite predictions and incorrect hashes. It does not open the actual seed/scratch prediction arrays. Future execution is one seed completed-mode invocation after independent review; no training, inference, test, refit, weights or family selection changes.

# Independent seed resource gate

The frozen Gram scientific result is not a prerequisite for seed23/37 replication. The seed launcher waits for the currently recorded Gram worker to have a terminal marker, verified /proc PID/start-tick exit and released shared physical-GPU lock. If the corrected Gram attempt has not launched, the preserved pre-fit failed attempt1 marker and receipt supply that terminal evidence; if it has launched, its current receipt and terminal marker take precedence. The seed worker still needs its own independent review, healthy idle GPU1/6 admission and shared lock. This amendment changes resource sequencing only; the accepted two-seed objective, initialization, selection and 100-epoch budget remain fixed. No test or validation-based decision is introduced.

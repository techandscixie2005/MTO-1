## 0. 一句话结论

**在一个 `A = μμᵀ` 精确成立的数据集上，把读出层改成形式完全正确的秩一外积，没有带来改进。**
这干净地说明：**瓶颈不在读出层，而在骨干特征与数据。** 继续做读出结构消融预期收益为零。

## 1. 关键前提：真值标签 A 精确地是 rank-1

提取脚本 `extract_qm9s.py:120` 直接由跃迁偶极构造 A：

```python
mu = s['transition_dipole_au']
s['A_au2'] = [[x*y for y in mu] for x in mu]     # = μμᵀ
```

数据集 README 亦写明 `A_au2 = 从选用偶极计算的 μμᵀ，派生量`。

在验证集 66860 条上实测（`rank_diag.py`）：

```
(|λ₀| + |λ₁|) / |λ₂|   中位数 = 1.165e-16
frac_share_lt_1pct = 1.000  (66860/66860)
frac_negative_lambda = 0.000
```

**A 是真值意义上的严格秩一矩阵，不是近似。** 由此：

- P-only 的 `A = μμᵀ` 与 ground truth 形式**完全一致**，不是建模假设。
- 原架构的 `A = CCᵀ`（`C = βI/√3 + Q₂ₑ`）可表达秩最高到 3，是**更宽**的假设类，
  需要自己学到把 β 压到 0、把 Q₂ₑ 压成秩一。

> **一个容易搞错的地方**：`Q = A − tr(A)I/3` 对秩一的 A **不等于零**，只有迹为零。
> 实测恒等式（随机矩阵，误差 2.8e-14）：
> ```
> ‖A−A_t‖²_F ≡ ‖Q−Q_t‖²_F + (s−s_t)²/3
> ```
> 即 **`Ls + LQ` 恒等于 A 上的归一化 Frobenius 损失**。LQ 不是冗余项，但也不提供新信息，
> 只是把 A 误差中非迹方向额外加权。

## 2. 四组真正在比什么

你描述的"P-only 只考虑 CG 耦合项"需修正：**两种架构的 CG 耦合是同一套**
（`pinned_reference/objective.py` 与 `frozen_reference/upstream/models.py` 都用
`FullyConnectedTensorProduct` 做 1o 与 M 的耦合）。真正的差异只有读出：

| | G1 / G2 原架构 | G3 / G4 P-only |
|---|---|---|
| A 构造 | `C = βI/√3 + Q₂ₑ`，`A = CCᵀ` | `A = μμᵀ` |
| 可表达秩 | 最高 3 | 只能 1 |
| 读出参数量 | 180,252 | 165,579（**小 8%**） |
| 骨干参数量 | 1,371,840 | 1,371,840（逐参数相同，哈希校验） |

且 `LQ` 在 G2/G4 中**不参与训练**：`objective.py` 在 `eta==0` 时
`return ls, ls.detach()*0, ls, ls.detach()*0`，连 Q 都不计算。

所以四组是 **{读出架构} × {A 损失给不给全}** 的 2×2，而非"CG vs 非 CG"。

`Ls` 定义：`mean_valid((tr A − tr A_t)²) / (3·sA2)`，`sA2=0.1324285377 au⁴`。

## 3. 验证集振子强度 R²

口径全部照抄 `evaluate.py::regression`（`R² = 1 − SSE/SST`），
`f = (2/3)·(E/27.211386245988)·tr(A)`，mask 为 `mask_A & mask_E & mask_f`。
三种 `f_*` 的区别**只在乘入哪个 E**，`tr(A)` 始终用模型预测值：

- `f_oracle`：乘**真实 E 标签**（诊断用，作弊）
- `f_common`：乘 **G1 的预测 E**（四组共用，跨组公平比较的主指标）
- `f_native`：乘**该组自己预测的 E**（端到端成绩；G2/G4 能量头冻结，无此项）

| 组 | 架构 / 目标 | f_common R² | f_oracle R² | f_native R² | trace R² | E R² |
|---|---|---:|---:|---:|---:|---:|
| **G1** | 原 MTO, LE+Ls+LQ | **0.3831** | 0.3880 | 0.3831 | **0.4412** | 0.9790 |
| G2 | 原 MTO, 仅 Ls | 0.3483 | 0.3569 | n/a | 0.4027 | 0.4656* |
| G3 | P-only, LE+Ls+LQ | 0.3381 | 0.3391 | 0.3384 | 0.3989 | 0.9783 |
| G4 | P-only, 仅 Ls | 0.3670 | 0.3669 | n/a | 0.4168 | 0.4639* |

\* G2/G4 能量头冻结，E 输出不是有效预测，该 R² 无意义。

## 4. 三个诊断

### 4.1 模型的秩结构（`rank_diag.py`）

预测 A 的两个小特征值占迹的比例：

| | 均值 `(λ₀+λ₁)/tr` | >20% 的比例 |
|---|---:|---:|
| 真值 | −0.0000 | 0.000 |
| G1（原架构） | **0.2797** | **0.628** |
| G3（P-only） | 0.0000 | 0.000 |

G1 只**部分**学到了秩一结构：平均 28% 的迹卡在两个小特征值上，62.8% 的分子
该比例超过 20%。相比之下 G3 精确为零。

### 4.2 瓶颈不在能量（`r2_val.py`）

```
G1: f_oracle = 0.3880   f_common = 0.3831   Δ = 0.005
    E R² = 0.9790
```

把预测 E 换成**真实 E**，f 的 R² 几乎不动 → 能量已学到 97.9%，**全部误差在 `tr(A)`**。

### 4.3 学不会的是"这个跃迁有多亮"（`mu_diag.py`）

由 `tr A = |μ|²` 与 A 的主特征向量还原 μ，分解幅度与方向：

| 指标 | G1 | G3 |
|---|---:|---:|
| R²(tr A) | 0.4412 | 0.3989 |
| R²(\|μ\|) | 0.3073 | 0.1723 |
| **R²(log\|μ\|)** | **0.0244** | **−0.3714** |
| 中位 \|cos(μ_pred, μ_true)\| | 0.6865 | 0.6333 |
| \|cos\| > 0.9 的比例 | 28.8% | 24.7% |
| 中位相对误差 on tr(A) | **71.6%** | **81.8%** |
| 最亮 1% 分子占 Ls 份额 | 54.1% | 53.3% |

**`R²(log|μ|) ≈ 0`**：模型对"哪些跃迁亮、哪些暗"**几乎什么都没学到**，只学到大致尺度。
典型样本 tr(A) 相对误差 72%，且最亮 1% 的分子吃掉 54% 的损失——**失败集中在强跃迁**。

## 5. 结论

### 5.1 读出不是瓶颈（主结论）

三条互相独立的证据：

1. **架构上**：A_t 严格秩一，故 G3 的约束形式正确；G1 的 `CCᵀ` 是更宽假设类，
   实测只把 28% 的迹留在小特征值上，**没能充分利用其灵活性**。
2. **复杂度上**：G3 读出参数量更小 8%，骨干逐参数相同。
3. **结果上**：G3 并未取胜（f_common 0.3381 < 0.3831；trace 0.3989 < 0.4412）。

一个 form 更正确、参数更少的读出在同骨干/数据/种子/优化器下**没有赢** → **瓶颈在读出之前**。

这也解释了四组读数为何互相矛盾（G3<G1 但 G4>G2）：读出层差异本就落在噪声量级。

### 5.2 这是过拟合，不是学不动

```
G1 训练 L: 0.9005 → 0.0854   （降 90%）
G1 验证 L: 最优在 ep25 = 0.5394，之后回升至 0.648
```

配置中 **`weight_decay = 0.0`，backbone dropout = 0.0**。模型有能力把训练集拟合到 0.085，
却在验证集停在 0.54。当前特征 + 数据量**不足以唯一确定目标**。

### 5.3 S7 是稳定复现的失败模式

| | S7 的 R² |
|---|---:|
| G1 | −0.047 |
| G2 | −0.290 |
| G3 | +0.204 |
| G4 | +0.163 |

两轮实验（`qm9s_full_EA_20260925` 的独立复核对 S7 张量误差退化、本轮 S7 的 R² 为负）
指向同一个失败点。样本量小（11 个近简并簇），但**稳定复现就不是随机误差**。

## 6. 限制（必须随结果一并报告）

- **全部为验证集且使用 `best.pt`**。`best.pt` 按验证损失选出，故这些 R² **系统性偏乐观**，
  测试集会更低。测试集仍封着，四组全部 `FIT_COMPLETE` 后由 `evaluate.py` 按协议统一打开。
- **四组仍在训练**（快照 01:52：G1 ep93、G2 ep91、G3 ep95、G4 ep95，best_epoch 25/26/92/91）。
  数字为瞬时快照，跑完会变。
- **单种子**。G1/G3 各只有一个种子，跨组比较按协议不得排名；5.1 的结论由架构/复杂度/结果
  三条独立证据支持，不依赖单点数字。
- **四组目标函数不同**（eta=1 为 LE+Ls+LQ，eta=0 为纯 Ls），总 Loss 不可跨组排名。
- **G2/G4 的 E 输出无效**（能量头冻结），其 `f_native` 与 E R² 不纳入指标。
- `tr(A)` 与 `f` 的 R² 使用**不同掩码**（前者 `mask_A`，后者 `mask_A & mask_E & mask_f`），
  不可直接相减。
- `f_oracle` 使用真实能量，仅为诊断，**不是可交付指标**。

## 7. 建议优先级

1. **关闭"改读出"这条线**。P-only 已证明读出不是瓶颈，继续做读出消融预期收益为零。
2. **补种子重复**（最高优先级）。在不知道"同模型换种子 val 差多少"之前，任何 <5% 的改进
   都无法判断是否噪声。本轮四组互相矛盾就是这个问题的直接代价。
   注意 `qm9s_full_EA_20260925` 的 `mto_seed23` 曾因 CUDA unrecognized error 中断，
   补跑时需记录为追加分析。
3. **优先查 S7**：用已有预测区分"强度预测错"与"态对应错位"（近简并导致真实态/预测态排序错位
   会让 R² 崩掉）。这是最可能低成本定位真因的一步。
4. **正则化**：`weight_decay=0` + `dropout=0` 是很便宜且当前完全未启用的杠杆，
   在 6 倍 train/val 差距下值得先扫一遍。若无效，则说明是固有标签噪声。
5. **若目标真是展宽光谱**：`R²(log|μ|)≈0` 说明纯几何 GNN 在此有硬上限，需考虑更强/预训练骨干、
   更多数据，或引入物理先验（跃迁密度局部性、近简并处理）。

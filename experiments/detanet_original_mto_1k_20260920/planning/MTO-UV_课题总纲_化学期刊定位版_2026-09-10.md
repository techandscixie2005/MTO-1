# 0. 项目定位与本版冻结决策

## 0.1 论文的中心不是“证明神经网络学出了真实 MO”

主张是：**MO 的组合思想可以启发一种有用的神经分子表示，而这种表示是否具有 chemical insight，必须由独立化学实验决定。**

需要回答的化学问题是：在局域激发、连续共轭、扭转削弱的共轭、以及电荷转移等条件下，模型是否能区分不同的激发空间组织；这种区分是否超越原子数、官能团和简单几何指标；它是否与模型对结构变化的预测有关。

数学内容服务于正确设计和可重复实现，主要放入 Methods／Supporting Information。主文用化学问题、概念图、受控系列和定量证据推进。**减少主文推导不等于降低对称性、标签定义和证据的要求。**

## 0.2 默认方案

| 项目 | 本版决策 |

## 0.3 相比旧总纲的明确修订

旧版将不同 tensor types 共享的 `c_ai` 设为主假设，并以 gauge-aware state-pair spectroscopy 作为强叙事。本版改为：**不共享系数的 MO-inspired assembly 是主模块；化学解释和结构响应是主问题；CG 与相位不变张量是支持方法。**[S0，§5.2、§16、§19]

上一轮讨论提出的 Gram 核、完整原子对读出与额外多模式轴，不作为本版必选组件。先把独立系数和有限通道的组装做清楚；仅在出现明确的信息压缩或远程几何瓶颈时，按 §19 的条件扩展。

# 1. 科学目标、假设与结果边界

## 1.1 四个主要假设

| 编号 | 待检验假设 | 支持它所需的证据 |
|---|---|---|
| H1：预测效用 | MO-inspired 的分子组装比简单逐态读出更适合当前任务 | 相同 backbone、数据权限与预算下的可重复比较 |
| H2：表示承载 | MTO 包含可读出的激发空间信息 | 冻结表示，对训练未使用的诊断量进行跨母体／跨骨架探针测试 |
| H3：化学对应 | MTO 的原子分辨组装与激发参与区域具有稳定联系 | 无诊断拟合的直接支持图比较、跨种子稳定性、混杂控制 |
| H4：解释用途 | MTO 有助于理解或预测结构改变引起的光谱和激发特征变化 | 成对结构干预、分支追踪、模型干预，以及预先登记的前瞻性计算 |

H2 不自动推出 H3，H3 不自动推出 H4。模型中能读出某信息，既不意味着某张权重图就是它，也不意味着该信息导致了预测改善。

## 1.2 第一篇论文的硬边界

主范围为中性、闭壳层、CHONF 分子；固定核构型下的垂直单重激发；无外磁场、无 SOC 的电偶极单光子线性吸收。仅在数据明确覆盖时，才扩展元素、净电荷和自旋。

第一篇不同时做三重态动力学、圆二色性、多光子过程、溶剂动力学、振电耦合、真实轨道重建和 Hamiltonian 学习。参考计算出现明显开壳层不稳定、强双激发或多参考特征时，应标记适用域边界，而不是强行解释。

**本项目首先是计算研究。量化计算对模型假设的检验称为“独立计算化学验证”；没有实际测量时，不称为“实验光谱验证”。**

## 1.3 “分子整体性质”在本文中的分层

第一层是状态相关的电子／空穴参与范围、空间展宽、片段参与和电荷转移特征，是主目标。第二层是跃迁强度、偏振及截断吸收响应，是直接预测与物理检验。第三层才是基态极化率、芳香性或一般电子离域指标，可作为独立迁移探针，但不纳入第一篇必须完成的主张。

基态 MO 的空间离域、激发电子／空穴的空间离域、电子—空穴分离、电荷转移和多组态混合不是同一个概念，不能用一个指标统称。

# 2. 第一性原理：哪些约束来自物理，哪些只是设计灵感

## 2.1 固定核电子问题

在非相对论、固定核、电荷与自旋条件明确的设定下，电子 Hamiltonian 可写为原子单位形式：

\[
\hat H_e(\mathbf R)=
-\frac12\sum_u\nabla_u^2
-\sum_{uI}\frac{Z_I}{|\mathbf r_u-\mathbf R_I|}
+\sum_{u<v}\frac1{|\mathbf r_u-\mathbf r_v|}
+\sum_{I<J}\frac{Z_IZ_J}{|\mathbf R_I-\mathbf R_J|}.
\]

其本征态与能量依赖核构型。实际 TDDFT、TDA 或其他计算协议是近似参考，不等于精确解。若训练只覆盖固定净电荷和自旋，几何与元素可以作为受限域输入；跨电荷／自旋时必须提供相应条件，不能期待网络从相同坐标猜出不同电子问题。相关非局域和电子自由度问题可参见 SpookyNet。[R12]

**不能从 Hamiltonian 直接推出“网络必须使用 MTO”。**它规定任务与对称性，不规定唯一神经结构。

## 2.2 AO→MO 提供的是组合原则

在原子中心基组中：

\[
\psi_p(\mathbf r)=
\sum_{i,n,l,m}C_{p,i n l m}\,
\chi_{i n l m}(\mathbf r-\mathbf R_i).
\]

系数通常依赖轨道、原子、径向基、角向基以及分子构型；没有普遍原则要求不同基函数使用同一个系数。真正 MO 的系数与基函数还受到归一化、基组重叠、电子结构方程和对称性约束。CEONET 的原始论文直接讨论了 AO 展开及轨道系数的张量变换。[R1]

由此得到本项目的设计灵感：

\[
\boxed{\text{原子中心、带对称性类型的局部特征}
\xrightarrow{\text{构型与状态条件化组合}}
\text{分子级模式}}
\]

但 MTO 没有电子实空间自变量，没有已知 AO 重叠矩阵，也不求解 Fock／KS 方程。**学习到的 atomic tensor 是原子中心描述符，不是完备 AO 基；其通道数也不是电子轨道数。**

## 2.3 “系数不共享”必须区分四个层面

**不同张量类型、不同通道、不同状态之间：不强制系数相等。**这符合本项目的组合灵感，并避免旧版不必要的低秩限制。

**不同原子之间：系数值可以不同，但生成系数的网络仍使用共享的原子规则。**不能给原子编号 1、2、3 分配永久专属参数，否则破坏原子置换一致性和跨分子可迁移性。对称等价原子在相同不变量环境下仍可能被迫给出相同标量系数；“不共享”不意味着故意破坏分子对称性。

**同一不可约张量内部的 m 分量：不能直接用任意独立的不变标量门控。**对标准 irrep 特征，线性通道映射具有 `W_channel ⊗ I_(2l+1)` 的形式；乘在一个 irrep 上的不变标量同样作用于整个多重态。否则一般不再与旋转变换相容。该约束与“不同类型共享同一 c_ai”不是一回事。[R2,R3]

**真实 MO 的 m 系数并不因此需要相等。**它们自己是随旋转混合的协变量；MTO 的标量 gate 与真实 AO 展开系数并非同一种数学对象。若未来希望显式对 m 做构型相关混合，需要使用按 `K(RX)=D(R)K(X)D(R)^T` 变换的张量算子或合法 CG 路径，而不是把普通 MLP 的输出逐分量乘上去。

因此本项目采用的准确表述是：

> **取消不同类型和通道之间的人为系数捆绑，同时保留等变性要求的分量结构。**

## 2.4 光学跃迁与空间结构

\[
\Delta E_a=E_a-E_0,\qquad
\boldsymbol\mu_a=\langle\Psi_0|\hat{\boldsymbol\mu}|\Psi_a\rangle.
\]

对相同电子数的正交态，跃迁数密度

\[
\sigma_a(\mathbf r)=\langle\Psi_0|\hat n(\mathbf r)|\Psi_a\rangle
\]

满足

\[
\int\sigma_a(\mathbf r)d\mathbf r=0,
\qquad
\boldsymbol\mu_a=-\int\mathbf r\,\sigma_a(\mathbf r)d\mathbf r.
\]

后两个式子直接来自态正交性和偶极算符；核偶极的态间项为零。由此可得跃迁偶极的原点不变性。但偶极只是空间分布的少数矩，有限条光谱不唯一规定完整跃迁密度。电子激发的空间诊断需要额外的一粒子跃迁密度／响应振幅分析。[R9,R10]

**将吸收称为“态间过程”是物理事实；要求网络必须显式学习两个 latent 再相乘，则是设计假设。**

## 2.5 相位不变的跃迁强度张量

在本项目的实数、无 SOC 设定下，单个孤立态可改变整体符号。跃迁偶极随之变号，但

\[
\boxed{A_a=\boldsymbol\mu_a\boldsymbol\mu_a^T}
\]

不变，且

\[
A_a\succeq0,\qquad A_a(RX)=RA_a(X)R^T,
\qquad A_a\in0e\oplus2e.
\]

跃迁量的任意相位与 phase-less learning 在 SchNarc 中已有明确讨论，不能把“发现相位问题”作为本项目的新贡献。[R8] 对称二阶张量的不可约分解见 e3nn。[R2]

本文使用“state-phase-invariant”或“相位不变”，尽量不单独写含混的“gauge-invariant”：这里没有证明有限基组下的电磁 length／velocity gauge 完全一致。训练和参考默认使用 length gauge。[R10]

## 2.6 为什么直接预测 A，而不默认预测普通极向量再平方

以下是本方案的对称性推导。若网络输出置换不变的普通极向量 `v(X)`，对反演对称且反演等价于同元素置换的结构，有

\[
v(X)=v(PX)=v(-X)=-v(X),
\]

因而 `v(X)=0`。然而不同电子态的反演宇称可允许非零的态间偶极。标量状态编号和 phase-less loss 不会改变这个几何向量网络的恒等式。

`A` 是偶宇称张量，不受上述强制归零限制。因此将直接张量头作为主方案。该论证针对“普通几何极向量＋不变状态索引”的架构，不是否定所有显式处理电子态规范的向量模型，也不意味着张量头已经解决所有点群简并。

## 2.7 对称性不是完整光学选择定则

O(3) 等变性保证正确的空间变换，并不自动赋予 MTO 真实电子态的点群表示。没有显式电子态对称性标签时，模型可能仍需从数据学习暗态和允许／禁阻跃迁。

不得把 CG 的角动量耦合规则直接称为本模型“严格实现了所有分子光学选择定则”。

# 3. 严格的 MTO 定义与模型接口

## 3.1 符号

| 符号 | 含义 |
|---|---|
| `i,j` | 原子索引 |
| `a=0,…,K` | 参考因子与能量排序的激发态索引；不是轨道编号 |
| `t=(l,p)` | O(3) 不可约表示类型 |
| `m` | 同一 irrep 内的几何分量 |
| `b` | Backbone 输入通道 |
| `k` | MTO 组装通道 |
| `H_i^(t)` | Backbone 原子张量 |
| `B_ik^(t)` | 投影到组装通道的原子张量 |
| `c_aik^(t)` | 构型、状态、类型、通道相关的不变标量系数 |
| `F_aik^(t)` | 原子分辨的实际组装项 |
| `M_ak^(t)` | 汇总后的分子级 MTO 通道 |

## 3.2 主定义

\[
B_{ikm}^{(t)}=\sum_bW_{kb}^{(t)}H_{ibm}^{(t)},
\]

\[
\boxed{F_{aikm}^{(t)}=c_{aik}^{(t)}B_{ikm}^{(t)}},
\]

\[
\boxed{M_{akm}^{(t)}=\gamma_N\sum_iF_{aikm}^{(t)}}.
\]

`γ_N` 在主版本中为固定的训练集尺度常数，而不是每个分子的不同归一化。所有状态、类型和通道的 `c` 不做相等约束。

单态 MTO 定义为

\[
\mathcal M_a=\bigoplus_{t,k}M_{ak}^{(t)}.
\]

`{F_aik^(t)}` 称为 **MTO assembly map**，是分子表示的原子分辨组装信息。必须区分“汇总后的 MTO latent 中可读出的信息”和“组装图中可读出的信息”，分别报告实验，不能将二者混称。

本版不另引入一个与 `k` 重复的模式索引。`k` 已提供有限的并行表示自由度。通道组合和旋转不对应真实 MO 的规范变换，不能逐通道强配 HOMO、LUMO 或 NTO1。

## 3.3 更一般形式与本版实际限制

最一般的同类型动态通道混合可以写为

\[
M_{akm}^{(t)}=
\sum_{i,b}\mathcal C_{aikb}^{(t)}(X)H_{ibm}^{(t)}.
\]

本版使用

\[
\mathcal C_{aikb}^{(t)}=\gamma_Nc_{aik}^{(t)}W_{kb}^{(t)}
\]

以控制成本。这里仍有沿输入通道 `b` 的结构限制，但**不同组装通道、不同类型的 c 没有被捆绑**。论文不能把本版称为“完全无约束的动态系数矩阵”；完整矩阵版本是可选容量对照。

## 3.4 与 attention／pooling 的关系

MTO 组装属于状态条件化的等变加权汇总家族，与 channel-wise attention、动态读出存在重叠。取消 softmax、允许符号、引入类型／通道独立系数，都不构成“与 attention 完全不同”的证明。

本项目的可能贡献是**化学启发的表示组织、明确接口及其可验证的用途**，不是声称发明了此前不存在的全部函数类别。强 state-token 对照与本模型等效时，应如实报告，不能靠重新命名制造差异。

# 4. 主模型设计：MTO-UV v2

## 4.1 输入与 Backbone

输入仅为核电荷、三维坐标，以及明确覆盖时的净电荷／自旋条件。状态编号 `a` 可以作为条件；真实激发能、真实强度、NTO、HOMO/LUMO、参考部分电荷等不能作为隐藏输入。

首选 DetaNet，因其已有张量性质与光谱预测实现。[R4] 首先核验实际源码的 cutoff、全局 attention、电子元素特征和输出 irreps，不能仅凭模型名称假设它完全局部或完全非局域。

初始读出类型为 `0e ⊕ 1o ⊕ 2e`，Backbone 层数初始为 3，通道预算以复现配置为起点。`l_max=2` 是成本选择，不是内部表示充分性的物理证明。不同实现间不应将同名超参数视为相同计算量。

## 4.2 不变上下文与系数生成

构造原子不变量

\[
u_i=\operatorname{concat}\left(H_i^{0e},
\{\|H_{ib}^{(t)}\|^2/(2l+1)\}_{t,b}\right),
\]

以及分子摘要

\[
g=\operatorname{concat}\left(\operatorname{mean}_iu_i,
\log(1+N),\text{element counts}\right).
\]

元素计数和尺寸信息必须同时提供给对应基线；它们可帮助任务，但也可能成为解释中的混杂因素。

\[
\tilde c_{aik}^{(t)}=
\phi_k^{(t)}(u_i,g,q_a),\qquad
\boxed{c_{aik}^{(t)}=\tanh\tilde c_{aik}^{(t)}}.
\]

可以共享 `φ` 的中间 trunk，但每个 `(t,k)` 有独立输出；状态通过 `q_a` 条件化。参数共享不意味着输出数值被约束相同。不施加鼓励不同类型系数相等或不同的额外损失。

默认 query 维数为 32，router 为两层、宽度 128 的标量 MLP，MTO 每类型 16 个通道。这些只是初始值；正式比较在相同搜索预算下冻结。

## 4.3 归一化与初始化

主版本不在原子维使用 softmax，也不强制每条 `c` 的全分子 L2 范数等于 1。原因是这些归一化不是 MO 归一化，并可能引入旁观片段竞争。正 routing、softmax、L2 routing 均作为消融，而不被先验判错。

取

\[
\gamma_N=1/\sqrt{N_{\mathrm{ref}}},
\]

其中 `N_ref` 为训练分子原子数中位数；它只是固定尺度，不能保证尺寸一致性。可使用合法的 irrep RMS 标准化稳定训练，但禁止逐 `m` 使用任意均值／方差缩放。记录标准化是在原子、分子还是数据集维上执行。

Router 末层用小幅随机初始化而非所有输出完全为零；PSD 输出因子也不得整体初始化为零。否则双线性关系和平方映射可能在起点产生不良梯度。

## 4.4 参考因子与状态关系

生成 `M_0` 作为共享 reference factor，以及 `M_1,…,M_K`。`M_0` 不被称作真实基态波函数或占据轨道。

默认使用允许路径的等变双线性关系：

\[
P_{0a}^{(L)}=
\operatorname{TP}_{L}(\mathcal M_0,\mathcal M_a),
\quad L\in\{0e,2e\}.
\]

`TP` 使用 CG 系数和可训练通道混合实现。对当前输入 `0e,1o,2e`，输出 `0e` 的路径包括 `0×0、1×1、2×2`；输出 `2e` 包括 `0×2、2×0、1×1、2×2`。路径受三角条件和宇称约束。[R3]

从 `Inv(M_0)、Inv(M_a)、P_0a^(0e)` 构成标量读出；张量读出可使用 `P_0a^(2e)` 与合法门控的 `M_a^(2e)`。这样仍然全部经过 MTO，但不将所有物理输出强迫经过唯一的双线性瓶颈。

主对照必须包含 `M_a-only`。CG 的作用是构造允许的等变关系，不是计算真实电子耦合。也不宣称有限通道、有限阶截断已对所有物理关系“完备”。

## 4.5 光谱解码

激发能：

\[
\hat E_a=E_*\operatorname{softplus}(h_E(z_a)),
\]

`E_*=1 eV` 为明确的输出尺度；计算振子强度时转换为 Hartree。

张量因子与输出：

\[
C_a=\frac{\beta_a}{\sqrt3}I+Q_a^{(2e)},
\qquad
\boxed{\hat A_a=C_aC_a^T}.
\]

`Q^(2e)` 必须通过与所用 e3nn 基一致的映射转换为对称无迹 Cartesian 矩阵。不得凭记忆将五个输出随意填入矩阵。

有完整标签时：

\[
\boxed{\hat f_a=\frac23\hat E_a^{\mathrm{Ha}}\operatorname{tr}\hat A_a}.
\]

不另设可与此关系矛盾的独立 `f` 头。仅有 `E,f` 时，采用非负标量 `s_a` 头并令 `f=(2/3)E s`，不训练无约束的偏振方向；版本记为 **MTO-UV-S**。完整张量版本记为 **MTO-UV-T**。

## 4.6 谱的统一定义

使用单位积分 Gaussian：

\[
K_\sigma(x)=\frac1{\sigma\sqrt{2\pi}}
\exp[-x^2/(2\sigma^2)].
\]

各向同性振子强度谱：

\[
S_{\mathrm{iso}}(E)=\sum_{a=1}^Kf_aK_\sigma(E-E_a).
\]

为避免方向平均的三倍因子混淆，本版定义定向强度张量

\[
\mathcal S(E)=\sum_a2E_a^{\mathrm{Ha}}A_aK_\sigma(E-E_a),
\]

于是

\[
S_{\mathrm{iso}}(E)=\frac13\operatorname{tr}\mathcal S(E),
\qquad S_{\mathbf e}(E)=\mathbf e^T\mathcal S(E)\mathbf e.
\]

这些是约定清楚的谱强度对象；不附加实验截面常数时，不直接标为绝对吸收截面。能量谱密度转成波长谱密度需要 Jacobian，不能只把横坐标换成 `λ=hc/E` 后仍声称积分强度不变。

## 4.7 单跃迁秩与简并

在本文实数、单个孤立跃迁的设定中，`rank(A)≤1`；平方张量头允许更高秩，因此主实验报告特征值和

\[
r_{\mathrm{eff}}=\frac{(\operatorname{tr}A)^2}{\operatorname{tr}(A^2)}
\]

的偏离。暗态分母接近零时不定义有效秩。

默认不加 rank penalty；可选消融为

\[
L_{\mathrm{rank}}=
\frac{(\operatorname{tr}\hat A)^2-\operatorname{tr}(\hat A^2)}
{(\operatorname{tr}\hat A)^2+\epsilon}.
\]

只对参考强度超过预设阈值且非简并的态使用，且权重很小。真正简并子空间使用 `Σ_a A_a`，不施加 rank-1。该正则不能取代强度监督。

# 5. 训练目标与训练协议

## 5.1 损失定义

对所有有效态做掩码平均：

\[
L=\lambda_E L_E+\lambda_sL_s+\lambda_QL_Q
+\lambda_{\mathrm{spec}}L_{\mathrm{spec}}.
\]

`L_E` 使用按训练集统计标准化的 Huber 损失；标准化参数只从训练划分计算。`L_s` 同时考虑线性强度与 `log(1+s/s_floor)`，避免只优化强态或只优化暗态。`L_Q` 比较无迹张量

\[
Q=A-\frac{\operatorname{tr}A}{3}I,
\]

在固定数据集尺度下的 Frobenius 误差。不要逐分子把所有强度归一成 1 后训练唯一主损失，否则丢失绝对强度。

基础尺度归一化后，初始取 `λ_E=λ_s=λ_Q=1`，`λ_spec=0.1`；标量版本令 `λ_Q=0`。先用逐态损失稳定训练，再在前 10% 训练步内逐渐引入谱损失。权重只在公共验证集、同等搜索预算下选择。

不加 NTO、CT、参与度、离域熵、MTO 正交性、电子／空穴标签损失。不得通过离域正则预先制造想要观察的现象。

## 5.2 状态顺序

沿用有效标签的能量排序，主损失按排序编号计算。不用严格正间隔累计参数化，因为它会排除真正简并。可加无正裕量的排序惩罚 `ReLU(E_a-E_(a+1))`；输出排序时必须将能量、强度、张量和对应 latent 一起排序。

“能量编号连续”不代表“激发特征连续”。扫描中的化学态追踪另按 §14 执行，不强迫一个 ordered state 在穿越时保持相同特征。

## 5.3 初始训练配置

初始使用 AdamW，学习率 `3e-4`，weight decay `1e-5`，warmup 5%，cosine decay，batch size 64 个分子，gradient clipping 5。最大 200 epochs 或预先记录的等效更新步数；这些并非经实验优化后的设置。

Pilot 至少 2 seeds，正式关键比较 5 seeds。采用相同数据划分和配对 seed；不得为 MTO 挑最好种子、给 baseline 报平均。所有基线具有相同早停规则和超参数搜索次数。

混合精度只在张量测试通过后启用；数据转换、矩阵诊断、旋转测试使用 float64。数值问题不能以“等变库保证正确”为由跳过。

# 8. Chemical insight 的独立参照：先定义物理量，再看模型

## 8.1 定义优先于软件默认值

对规定的正交单粒子基，记分析矩阵为 `T_a`，行表示 hole 侧、列表示 electron 侧。对于真实一粒子跃迁密度，它有明确的态间定义；对于 CIS／TDA，它可由激发振幅构造。完整 TDDFT 的 `X`、`Y` 响应振幅不能不加说明地当作一条普通 CI 波函数。[R9,R10]

本项目为工程可重复性，规定：**QM9S 协议为完整 TDDFT 时，第一阶段使用显式标记的、归一化 X-only / CIS-like NTO 诊断；它是独立电子结构诊断，但不冒充完整 TDDFT 的精确跃迁密度或弛豫激发态密度。**同时保存 `X,Y`，报告去激发振幅相对大小，并在方法敏感性子集上比较 TDA 和包含 `Y` 的规定分析。

该限定有实际必要：本次核验的 PySCF `get_nto` 实现明确说明其完整 TDDFT 分析把 `X` 归一化并忽略 `Y`。[R11] 不能将软件接口名字当成方法定义。导出原始 `X,Y` 的独立副本，先保存原始跃迁性质，再做诊断；任何会原位归一化振幅的调用不得改变用于后续物理计算的对象。

对 TDA，`Y=0`，可直接采用其规定归一化后的 `X`。对完整 TDDFT 另存

\[
r_Y=\|Y\|_F^2/(\|X\|_F^2+\epsilon)
\]

作为分析约定敏感性指示量，不将它单独称为多参考诊断。

## 8.2 NTO、参与分布与空间离域

对所选并记录的 `T` 做 SVD：

\[
T=U\,\mathrm{diag}(s_r)V^\dagger,
\qquad
\Omega=\|T\|_F^2,
\qquad
w_r=s_r^2/\Omega.
\]

NTO 的基本作用是给出跃迁分析矩阵的紧凑分解，而不是保证只有一对轨道。[R10,R15]

定义归一化边缘矩阵

\[
D_h=TT^\dagger/\Omega,
\qquad D_e=T^\dagger T/\Omega.
\]

在上述固定分析约定下，两者半正定且迹为 1。通过 NTO 或基函数得到对应的空间分布，再计算原子／片段参与度。对 `Ω≈0` 的对象不强行生成分布，标为该分析不可定义。

在完整 TDDFT 的 X-only 约定下，这些称为 **NTO-X excitation-participation distributions**；不把它们写成实测电荷或完整激发态电子密度。若使用更完整的响应／密度分析，由接口测试确认定义后单独存储，不能与 X-only 数据混为一个列。

## 8.3 原子划分与基组敏感性

默认使用 Löwdin 正交化后的原子基函数归属进行参与度分析。如果 `T_AO` 是非正交 AO 表示下的密度核系数矩阵，则先按该约定使用

\[
\widetilde T=S^{1/2}T_{\mathrm{AO}}S^{1/2},
\]

再构造边缘矩阵；实现必须通过 `C^TSC=I`、总归一化和重建测试。

得到

\[
h_i=\sum_{\mu\in i}(D_h)_{\mu\mu},\quad
e_i=\sum_{\mu\in i}(D_e)_{\mu\mu},
\qquad q_i=\frac{h_i+e_i}{2}.
\]

`q_i` 是本项目与无方向 MTO 支持图比较的主要参照。它不区分电子和空穴，不能据此辨认 CT 方向。所有原子版本为主；重原子版本要对模型和参考同步重新归一化，并作为敏感性结果。

原子人口分析有基组和划分依赖。关键结论至少在一个替代划分或更大基组子集上复核。不得把 `|C_AO|²` 在非正交 AO 基中直接当作无歧义概率。

## 8.4 必须分开的诊断量

空间参与度：

\[
P_h=\frac1{\sum_i h_i^2},\qquad
P_e=\frac1{\sum_i e_i^2},\qquad
P_{\mathrm{sym}}=\frac12(P_h+P_e).
\]

这里原子数越多并不必然意味着真实电子更离域，所以后续必须控制分子尺寸。

电子／空穴质心距离：

\[
D_{he}=|\langle\mathbf r\rangle_e-\langle\mathbf r\rangle_h|.
\]

空间展宽：

\[
\ell_h^2=\langle|\mathbf r-\langle\mathbf r\rangle_h|^2\rangle_h,
\quad
\ell_e^2=\langle|\mathbf r-\langle\mathbf r\rangle_e|^2\rangle_e.
\]

优先使用空间积分的质心和二阶矩；仅以原子中心近似时另标 `atomic-center proxy`，尤其不能用于声称辨认弥散的 Rydberg 轨道。

NTO 对数复杂度：

\[
P_{\mathrm{NTO}}=\frac1{\sum_rw_r^2}.
\]

**`P_NTO` 是多个 NTO 对参与的程度，不是空间离域长度。**空间上高度离域的单对 NTO 完全可能有 `P_NTO≈1`。

片段电荷转移数：

\[
\Omega_{AB}=\sum_{\mu\in A,\nu\in B}|\widetilde T_{\mu\nu}|^2,
\quad
\overline\Omega_{AB}=\Omega_{AB}/\Omega.
\]

片段划分预先冻结；行／列的 hole→electron 方向必须由小分子算例确认。`Σ_(A≠B) Ω̄_AB` 依赖片段定义，不是普适、分割无关的 CT 真值。主分析报告连续值，分类阈值仅是操作性约定。[R9]

## 8.5 不能混淆的量

Attachment／detachment density、弛豫密度差 `ρ_a−ρ_0`、跃迁密度的对角部分、NTO-X 的电子／空穴参与分布，不能互换。对 signed density difference 取绝对值以后得到的图，也不等于 `q_i`。

本项目主结果只围绕上述预先定义的参与度与空间尺度；密度差图作为补充，不用一张漂亮的差分图替代这些量。

# 9. MTO-Chem：自建数据的组成与隔离

## 9.1 设计原则

数据库用于检验假设，不用于“展现预定结论”。优先提供受控变量、同母体多状态、结构匹配对和失败案例，而不是追求随机大分子数量。

主范围先限制于以价激发为主的共轭／局域激发体系。强 Rydberg、强双激发、复杂多参考和完全相同片段的严格简并体系作为边界与压力测试，不与主测试混合计算单一分数。

## 9.2 建议规模与用途

以下是可按资源缩放、但必须按母体和分子族隔离的初始预算：

| 子集 | 母体规模 | 几何预算 | 使用权限 |
|---|---:|---:|---|
| Chem-dev | 20 | 约 100 | 流程调试、诊断实现审计、探索性案例；不是最终证据 |
| Chem-probe-train | 40 | 约 240 | 冻结表示后的探针训练；迁移协议可使用其光谱标签 |
| Chem-probe-val | 10 | 约 60 | 探针超参数；迁移光谱模型的验证 |
| Chem-test | 40 | 约 280 | 定型后的独立盲测；不得据此修改模型 |
| Chem-prospective | 20 | 约 80 | 冻结后预先登记预测，再进行量化计算 |
| 合计 | 约 130 | 约 760 | 根数按记录保存，不把所有 roots 当成独立分子样本 |

同一条扫描所有点必须同组。同一母体的不同构象不能跨组；由同一模板生成的高相似系列，还需在 `family_id`／`scaffold_id` 层面隔离。正式测试应覆盖多个独立骨架，而不是用一个扫描的几十个点制造“很多独立样本”。

最先只建立 Chem-dev 中约 12 个母体、每个 3–5 个点的小试验。它用于确认参考计算、态追踪和解释接口能工作，不用于提前宣布 H2–H4 成立。

## 9.3 三个主化学系列

**系列 A：共轭长度与共轭中断。** 设计连续共轭、交叉共轭或饱和中断的匹配系列；提供尺寸相近但电子连通性不同的对照。可从短链烯烃、共轭羰基和芳基连接片段起步。不要仅将短分子与长分子相比较。

长 polyene 的低能暗态和双激发特征可能超出简单单参考响应的可靠范围。遇到相应案例，需高层级检查或独立边界标记；不能因为趋势不符合预期就删去这些样本。

**系列 B：同分子的扭转扫描。** 选择可控的芳基—芳基、芳基—烯基或其他共轭连接；扫描 `0°,15°,30°,45°,60°,75°,90°`，优先使用固定二面角、其余自由度放松的结构，并保留少量刚性旋转对照以区分几何协同效应。相同原子数和连接关系下，检验表示是否能追踪激发特征变化。

**系列 C：供体—桥—受体与局域激发对照。** 在 CHONF 范围内改变供体、受体、桥长度和扭转，比较局域激发与不同程度的片段转移。不预先把含供受体官能团的全部根标成 CT；标签来自规定的参考诊断。

所有预期变化是待检验假设。不能预设离域越大必然红移、CT 越强振子强度越小，或扭转变化必然单调。

### 首批 Chem-dev 的 12 个起始母体

为避免启动时仍需从零挑选分子，采用以下**拟定模板**。本次仅检查了 SMILES 可解析、净电荷为零及无显式自由基；尚未做几何优化、激发态计算或化学适用性验证。模板是开发样本，不是事先挑定的成功案例。

## 9.4 两类压力测试

**对称性与简并。** 选少量高对称结构、允许和禁阻跃迁以及对称性微扰；在等价的简并根之间比较合并响应，避免要求模型学习数值程序任意选取的方向或片段定位。

**旁观片段／距离。** 使用局域激发能不相同的两个片段，做距离和相对取向扫描；检查远处不相关片段是否因全局归一化等原因显著改变目标激发。相同片段的简并极限只比较相应子空间／总谱，不要求唯一的单态定位。

## 9.5 与 QM9S 的重叠审计

每个自建母体记录是否出现在 QM9S train／validation／test。已见分子的全新电子结构标签可以检验“未监督信息可读取”，但不能同时称为“未见分子外推”。真正 Chem-test 的化学泛化主结果应优先使用不在公共训练集中的母体与骨架。

几何层面新点、分子身份新点和化学骨架新点分开报告。

# 10. 自建数据的量化计算与质量控制

## 10.1 两层参考，不混成一个真值

**QC-Q：与 QM9S 标签对齐的参考。** 在本地源数据审计确认后，使用相同电子结构方法、基组、TDA／TDDFT 和 gauge，在自建几何上计算光谱和响应振幅。目的在于评价几何泛化而不是同时混入方法误差。若无法复现原程序协议，则标为近似复现，并用一组公共分子量化差别。

**QC-C：化学结论的敏感性参考。** 对分层抽取的约 15%–20% 样本、所有主文关键结构和前瞻性主要发现，额外建议计算 `TDA-CAM-B3LYP/def2-TZVPD`；对关键样本再比较相同泛函／基组下完整 TDDFT。这里的配置是一个预先声明的实用候选，不是已证明对所有 CT／Rydberg／多参考体系最准确的方法。

QC-Q 与 QC-C 使用同一几何，保留两套结果。方法改变后按过渡特征匹配根，不能把两个计算的相同 root number 视为同一激发。若结论依赖某个方法，按方法依赖结果报告。

价激发为主的初始范围不需要把整个数据库变成最高等级 benchmark；但存在明显弥散特征时，原 QM9S 基组不能作为唯一化学依据。关键小分子可用 EOM-CCSD 或可用的更高层级方法复核；这些方法也有适用范围，不被称为无误差真值。[R13]

## 10.2 几何协议

几何生成和电子激发计算分开记录。对公共分子保留原始 QM9S 坐标；对新分子采用统一优化协议，初始候选为 `B3LYP-D3(BJ)/def2-SVP`。它是新数据的几何协议，不冒充原 QM9S 几何优化协议。

扭转扫描记录约束原子索引、目标角度、实际角度、优化是否收敛，以及是否发生质子转移或连接关系变化。对主文案例与一定比例的结构做频率／稳定性检查；受限扫描点不被标为完全自由的势能面极小点。

## 10.3 根数与状态覆盖

自建计算默认至少求 15 个 singlet roots；参考分析所需的目标分支接近根上限时增加到 20。模型正式输出仍为训练过的最低 K 态，不能把新 query 任意扩成第 15 态并声称零样本预测。

跟踪分支离开模型 K 态窗口时，记录 coverage failure，不能只删除该扫描后半段。简并簇被 K 截断时，不能用部分簇评价完整子空间响应。

## 10.4 每条计算必须保存的内容

保存原始输入、完整日志、几何、程序与版本、方法／基组／积分网格、净电荷／自旋、SCF 和响应收敛状态、全部有效根能量、length-gauge 跃迁偶极与振子强度、响应 `X,Y` 的原始副本、MO 系数、AO overlap、分析约定及诊断量。

无需为所有状态保存大体积 cube 文件；主文代表样本及抽样审计保存 cube，其余保存足以重新生成的矩阵和检查点。所有派生标签带 `analysis_version`。

## 10.5 数值质量阈值

初始 QC 配置采用 SCF 能量收敛量级 `1e-9 Hartree`、响应残差量级 `1e-7`；实际关键字按所用程序文档确认。利用分层样本加严收敛和网格，确认诊断变化小于待检验的化学效应。

记录负／虚激发能、明显 SCF 不稳定、异常强度、基组近线性相关、振幅归一化失败和根数不足。失败的重试顺序固定：增加迭代与稳健收敛 → 更严格数值设置 → 人工标记适用域问题。不得对测试失败样本临时换方法并混入同一参考列。

剔除规则在查看模型误差前制定，按原因公布全部剔除数量。

## 10.6 计算预算

先用约 20 个代表性结构测量不同原子数、基组和根数下的 CPU/GPU 小时与峰值内存。总预算由实测均值／上分位数乘计划规模估算，并预留重算成本。

不预写“几天完成”或固定每分子耗时。没有用户硬件和程序授权信息，无法给出可信绝对用时。资源不足时先降低分子族数量和扫描密度，不通过删去困难测试点、放松参考定义或隐藏失败来节省预算。

# 11. 三条数据使用协议：冻结、迁移、探针不得混写

## 11.1 Z0：QM9S-only 光谱训练后的冻结检验

Backbone、router、MTO 和光谱头只在 QM9S 训练。自建数据不更新主模型；直接比较 QC-Q 光谱，并对独立诊断进行盲测。

QC-C 用于方法敏感性时，先匹配 QC-Q 与 QC-C 根。没有可信映射的状态，不作“同一激发的跨方法对应”结论，另报告匹配率和不确定案例。

这是最强的“从小分子公共光谱监督产生新化学空间表示”的试验，也可能因分布外推而失败；失败不自动说明所有 MTO 迁移方案无效。

## 11.2 Z1：使用自建光谱标签的迁移

允许使用 Chem-probe-train 的 `E,f` 或 `E,A` 更新模型；验证只用 Chem-probe-val 的对应光谱标签。所有基线获得相同的标签、训练步数和超参数搜索预算。

诊断量依然不进入主模型损失。此时可以说“没有轨道／密度监督”，不能说“从未使用自建数据训练”。Chem-test 与 prospective 仍保持隔离。

若 QC-C 形成足够一致的迁移子任务，应单独建 split 和方法标签，不能把 QC-Q 与 QC-C 直接混入同一监督列。

## 11.3 Frozen probe：独立的下游学习阶段

冻结主模型，用 Chem-probe-train 的诊断量训练简单 probe，Chem-probe-val 选择正则，Chem-test 只评价一次。

主模型未用轨道监督，与 probe 使用了诊断标签，是可以同时成立的。论文必须写清楚监督作用在哪个阶段。probe 的成功证明特征中有可读取信息，不证明零样本直接预测这些诊断量。

Chem-dev 的诊断结果一旦用于修改架构，就属于诊断辅助开发。仍可保持“主模型无轨道损失”，但不能称整个方法选择过程完全未接触电子结构信息。

# 12. 基线与消融：每一个主张都要有对应对照

## 12.1 必做的主基线

| 编号 | 方法 | 比较目的 |
|---|---|---|
| B0 | 同 Backbone 的 pooled direct multi-output | 分子汇总直接预测是否已足够 |
| B1 | state-index-conditioned pooled readout | 状态编号的贡献是否已解释结果 |
| B2 | 等变 state token／cross-attention | MTO 是否优于强状态条件化表示 |
| B3 | 旧版 shared-c MTO | 取消类型／通道捆绑是否有实际作用 |
| M | 本版 type-and-channel-specific MTO | 候选主模型 |

B2 至少包含一个状态条件较早进入特征处理的版本，而不只是最后拼接 state index。token 可读取相同阶数的张量，并使用相同物理输出头；不能给 MTO 用 A 标签而只让基线学标量 f。

各方法报告总参数、Backbone 参数、读出参数、每步时间、显存和预测吞吐。优先匹配总参数与有效训练预算；若无法同时匹配参数和时间，分别做参数匹配、时间预算匹配，不声称两者都相同。

## 12.2 最小消融集合

| 对照 | 仅改变的因素 |
|---|---|
| Shared → type-specific → type-and-channel-specific | 系数捆绑层级 |
| Signed tanh → positive gate | 系数符号自由度 |
| 无分子归一化 → L2／softmax | 原子竞争和尺度处理 |
| `M_a-only` → reference pair | 参考因子是否有作用 |
| 同一 pair 的简单合法读出 → CG relation | 关系构造是否增加价值 |
| `C=8,16,32` 的 MTO 通道 | 容量与多模式是否构成瓶颈 |
| 相同 MTO、不同 A／标量／向量头 | 输出目标与主模块的贡献分离 |

不展开所有因素的全排列。先用 pilot 和验证集定位最有区分度的单因素比较，再冻结正式集合。

“generic pair MLP”只能接收不变量；若输出张量，必须配备合法等变张量基。不得把将 Cartesian 分量任意展开的非等变 MLP 当作唯一弱对照。

## 12.3 解释基线

冻结原 Backbone 的普通分子特征、B1 的状态表示、B2 的 state token、B3 的共享 MTO 都进入相同 probe 流程。对原子支持图，比较以下信息权限相同的替代项：原子类型／共轭图描述符、普通 attention 支持、相同输出的梯度归因、以及可实现的 atom-wise excitation contribution 基线。

OMNI-P2x 的公开模型可以作为外部参照，但其训练规模、方法和潜在数据重叠与本项目不同，不能代替同数据权限基线。[R7] CEONET 使用轨道输入，属于另一个信息条件，不进入“几何输入无轨道监督”主排名。[R1]

# 13. MTO 如何解释：分子 latent 与组装图分别检验

## 13.1 分子 latent 的 probe

对标量诊断，使用旋转不变的 probe 特征，包括 `M_a^(0e)`、同类型通道内积、与 `M_0` 的合法标量关系。不能直接展平未经对齐的向量／张量分量交给普通线性回归，并让坐标框架成为捷径。

主 probe 用 ridge regression；输入特征只用 probe-train 的均值／方差标准化，删除训练集常数列。正则初始网格固定为 `10^(-6),10^(-4),10^(-2),1,10^2,10^4,10^6`，按 family-grouped validation 选择，不接触 Chem-test。补充一层小 MLP 只作为可读取性上界；如果只有大模型 probe 有效，不称“简单可解释的组织”。所有表示使用相同的探针容量和调参预算；维度不同时同时报告原始维度与固定维数、仅在 probe-train 拟合的降维对照，防止把更大特征数误归因于更好的组织。

输出诊断至少包括 `P_sym`、`D_he`、`P_NTO`、片段参与量。主终点选择 `P_sym`，其余分开报告并控制多重比较。

## 13.2 参数为零的直接支持图

不拿 `c` 的绝对值直接当电子分布。优先使用实际参与预测的原子项 `F`，在每类型固定尺度下定义

\[
G_{a,ij}=\sum_t\frac{
\langle F_{ai}^{(t)},F_{aj}^{(t)}\rangle_F
}{C_t(2l+1)\zeta_t^2},
\]

其中 `ζ_t` 只由公共训练集的特征统计确定，不用诊断标签拟合。

\[
p_{ai}=\frac{G_{a,ii}}{\sum_jG_{a,jj}}.
\]

这里的 Gram 矩阵用于事后分析，不是本版新增的前向原子对模块。主支持图只需计算对角线，不增加预测中的二次复杂度。

该 `p` 对空间旋转、反演及相同类型内整体正交通道变换不变；但不对任意网络重参数化都不变。因此稳定性必须实验测量，不能因其是 Gram 对角线就宣称解释唯一。

与之分开报告 routing-only 支持图 `p_c∝Σ_(t,k)c²`，以判断“系数外观”与“实际特征贡献”是否不同。

## 13.3 Latent 支持度指标

\[
P_a^{\mathrm{MTO}}=1/\sum_i p_{ai}^2,
\quad
\bar{\mathbf R}_a=\sum_ip_{ai}\mathbf R_i,
\quad
\ell_{a,\mathrm{MTO}}^2=\sum_i p_{ai}|\mathbf R_i-\bar{\mathbf R}_a|^2.
\]

命名为 `latent participation`、`latent spatial spread`。在经过独立验证前，不叫电子离域长度、激子半径或电子／空穴距离。

`G` 是对称对象，不天然具有 hole→electron 方向。不能从其非对角元素符号直接识别电荷转移方向。

## 13.4 抵消与非识别性审计

一个分子可能有很多大的 `F_i`，但求和后相互抵消。因而“大支持区域”不必然对输出重要。对每类型记录

\[
\eta_a^{(t)}=\frac{\|\sum_iF_{ai}^{(t)}\|_F^2}
{N\sum_i\|F_{ai}^{(t)}\|_F^2+\epsilon},
\]

它在非零情况下位于 0 到 1，用来监测汇总抵消，不称作量子相干度或成键指标。

主模型不给光谱预测留一个可以完全绕过 MTO 的强大旁路。即便如此，也要用消融／干预确认支持区域与预测相关。

## 13.5 对照指标

直接图比较采用 Jensen–Shannon divergence、Bhattacharyya overlap `Σ_i√(p_i q_i)` 和片段参与误差；相关性作为辅助而非唯一指标。先对每个状态计算，再按几何、母体、分子族汇总。

总支持图、每类型支持图和通道级示意分别报告。通道级“最佳对应”若通过事后挑选得到，只作为探索性结果；不能将选中的一个通道当成整体方法的盲测分数。

# 14. 结构变化、态追踪与干预

## 14.1 两种不同的比较

**能量排序任务：** 始终比较参考和模型的第 a 个有效根，这是公共 benchmark 的定义。

**激发特征追踪任务：** 沿扫描匹配同一条激发特征分支，用于化学解释。两者在态交叉或 avoided crossing 附近可能不同，必须双轨报告。

不能只用能量最近原则作为所有扫描的身份匹配。优先使用规定分析矩阵或 NTO 子空间重叠；原子顺序、AO overlap、跨几何基函数重叠和坐标框架均需一致。相邻点使用全体候选根的一对一匹配，并输出置信度及候选差距。

遇到低置信度，增加扫描点和参考根数，仍不确定则标为歧义区。不得人工挑一条最好看的平滑曲线。

## 14.2 真实简并与近简并

真正简并子空间可更换基，单个态的跃迁方向、NTO 和支持分布未必唯一。对已确认的简并簇 `D` 使用

\[
A_D=\sum_{a\in D}A_a
\]

及相应未单态归一化的跃迁矩阵强度总和构造合并诊断。不要先把每个根分别归一化后简单平均，并声称对任意子空间基变换不变。

仅仅能量接近不等于存在任意子空间规范。近简并时可额外评价谱或窗口聚合，但称为有限分辨率评价，不称为精确 gauge invariance。

## 14.3 物理结构干预

扭转、共轭中断、取代基改变、片段分离分别计算参考 `ΔE、Δf、ΔP_sym、ΔD_he`。比较模型对变化方向和大小的预测，同时报告参考本身不呈单调变化的案例。

关键评价是同一母体内部的有限差分和匹配对，而不只是将所有分子混合后计算一条总体相关系数。基线必须包括只用扭转角、尺寸、共轭图等可见结构特征的模型。

## 14.4 模型内部干预

对 `F_ai^(t)` 施加相同作用于整个 irrep 的原子／片段 mask，比较输出变化；并与同元素、同数量、相近位置的随机 mask 对照。将 c 在适当的同元素原子间置换或替换为平均路由时，固定其余计算和归一化规则。

这些干预检验模型依赖，不等于改变了真实电子结构。将大部分 latent 置零可能制造分布外输入，因此只用它们作为辅证。可比较完整删除与小幅连续扰动，避免用单一极端 mask 得出因果机制结论。

## 14.5 分离极限

对非相互作用片段，覆盖相同能量窗口内全部相关跃迁的总谱应趋向可加。这是独立片段响应的检验条件，不是本架构自动满足的保证。

固定取“每个体系最低 K 态”可能截取不同跃迁，不能直接用这种不同截断检验总谱可加性。对应局域分支也必须先匹配，而不是仅比较加入片段前后的 S1。

# 16. 指标、统计与混杂控制

## 16.1 光谱预测指标

逐态报告能量 MAE／RMSE、f 的 MAE、线性与对数强度误差、bright／dark 分层误差和排序冲突。强度误差同时给出每态与每分子聚合，避免高编号态或少量强峰控制总分。

张量版本报告 `A` Frobenius 误差、trace 误差、无迹部分误差、负特征值检查、秩偏离，以及足够明亮且主轴可定义的状态的无符号轴夹角：

\[
\theta=\arccos|\hat{\mathbf n}\cdot\mathbf n|.
\]

暗态和简并簇不强求唯一方向。bright 阈值只根据训练／验证规则定义，不能为了得到较低角误差在测试后提高阈值。

谱指标同时给出原始强度误差、积分强度误差、cosine similarity 和归一化非负谱的 Wasserstein 距离。零强度谱单列；不得通过除以零或任意补值伪造形状指标。

## 16.2 三个预先登记的主终点

**P1：实用预测。** 在固定低数据或预先选定 OOD 主划分上，对最强同权限 baseline 的预定义光谱／强度损失差值；同时要求激发能没有超出事先确定的非劣裕量。

**P2：表示承载。** Chem-test 上冻结 ridge probe 对 `P_sym` 的按母体聚合 MAE，相对于 B2 和简单结构／output-only 基线的差值。

**P3：直接化学对应。** Chem-test 上无诊断拟合的 `p_MTO` 与 `q_ref` 的 JSD，相对于同权限解释基线的差值；辅以扭转系列内的变化一致性。

可把 5% 预测改善、10% probe 误差改善作为项目内部的初始“值得继续”目标，但它们是预登记的实用目标，不是化学期刊标准。最终报告连续效应量与置信区间，而不是只报告“过线”。

不能在结果出来后，从大量指标中任选一个改善最大者改成唯一主终点。

## 16.3 置信区间与独立样本

比较使用相同测试样本、划分和 seed 的配对差值。对化学数据按母体／骨架做分组 bootstrap；建议同时给出 seed 变异与样本组变异，而不是把所有几何×所有态当独立样本。

在较少分子族下明确报告族数和宽置信区间。多终点推断使用预先声明的 Holm 校正，或将次要结果明确标为探索性。不要只报告 p 值而省略实际误差与效应量。

## 16.4 必做的混杂基线

probe 至少比较以下输入：`N_atoms`、heavy-atom count、元素组成、二维共轭／官能团描述、扭转角等几何变量；仅使用模型输出 `E,f`；以及原 Backbone 的普通分子表示。

使用同一训练／验证／测试分组。可以对诊断量先用简单描述符回归，再评价 MTO 对残差的额外预测能力；残差模型也只在 probe-train 拟合。

同分子不同状态是关键对照：若同一分子所有 MTO 都给出近乎一样的支持图，却只在跨分子上与原子数相关，不能声称有状态分辨的 chemical insight。

## 16.5 空模型与稳定性

至少包括随机初始化模型、随机标签训练的小规模模型、固定均匀 routing、适当的 routing shuffle。原子置换作为数学对称性测试时，应重新计算整个网络；它与故意打乱内部 c 的破坏性实验不是同一件事。

跨种子直接比较汇总支持 `p` 和片段参与，不强迫原始通道逐个相等。涉及 latent 子空间比较时，仅在训练／开发数据拟合对齐，测试集上不能寻找使图最像的通道排列。

# 17. 前瞻性计算化学：让 insight 产生可检验的用途

## 17.1 要检验的问题

不是让 MTO 重复“共轭增加可能红移”的常识，而是预先判断：**在尺寸、组成或预测吸收能相近的候选中，哪些结构编辑会改变激发参与区域，哪些只是改变能量而不改变空间组织？**

可优先选择两个编辑轴：共轭连接的几何约束与供受体连接位置。具体母体由 Chem-dev 的可计算性筛选决定；定型后再生成未计算候选。

## 17.2 固定流程

在量化计算前冻结模型、probe、候选生成规则、选择分数及待检验方向。主比较使用完全相同候选池和相同 QC 预算：property-only 策略只看光谱输出；MTO 策略在相同基础上加入预先确定的表示诊断或状态参与预测。

建议先生成 60–100 个候选编辑，分层选取 20–30 个进行独立计算，其中包括两种策略都选中的候选、仅各自选中的候选，以及随机对照。实际数量由先导成本测试冻结。

对全部选中结构报告预测和参考，不只展示成功者。模型选择的候选可能因几何重排、态交叉或适用域问题失败，这些结果进入统计。

## 17.3 可接受的化学贡献

支持以下表述的证据可以是：MTO 帮助区分同样红移但激发空间组织不同的编辑；帮助定位引发状态特征交换的扭转区间；在同预算下更准确地挑出参与范围改变较大的候选。

这证明某种模型辅助分析的用途，不等于发现了新的普适电子结构定律。所有计算仍基于指定参考方法；有实际光谱测量再另行加入实验验证。

# 18. 数学与工程验收：扩大训练之前必须通过

## 18.1 不共享系数的等变性验证

若 `c_aik^(t)` 在旋转下不变，且 `B_ik^(t)(RX)=D^(t)(R)B_ik^(t)(X)`，则

\[
M_{ak}^{(t)}(RX)=
\gamma_N\sum_ic_{aik}^{(t)}D^{(t)}(R)B_{ik}^{(t)}
=D^{(t)}(R)M_{ak}^{(t)}(X).
\]

推导不需要不同 `t,k` 共用 c。它同时说明必须检查 c 的输入确实是不变量，而不是偷偷包含实验室坐标分量。

## 18.2 自动测试

每次代码变更至少在随机结构和若干高对称结构上测试：元素与坐标联合置换、全局平移、随机 SO(3) 旋转、反演／反射、内部 irrep 变换、A 的协变、f 的不变、PSD、标签符号翻转不改变 A、batch 拆分与合并结果一致、padding／masked roots 不污染有效输出。

误差采用相对加绝对混合容限，初始 float64 `1e-7–1e-6`，float32 `1e-5` 量级；近零目标以绝对容限为主。容限按特征尺度和实际后端审计，不靠放宽到遮住 bug。

## 18.3 对称性合成任务

用一对相同原子的轴向结构构造人工标签 `A=n n^T`，检查普通极向量平方头的限制与直接张量头的可表达性。该标签是数学单元测试，不宣称对应该分子的实际电子跃迁。

增加随机全局符号翻转的跃迁偶极标签测试，以及真正简并的合成子空间旋转测试。仅对合并张量检查相应不变性。

## 18.4 最小过拟合与梯度测试

先在 32–128 个分子上尝试过拟合，排查数据、mask、head、loss 和梯度。记录各模块梯度范数；检查 c 是否全部饱和、所有状态是否塌缩到相同表示、张量头是否长期零梯度。

不能将“训练集也拟合不了”的实现直接带入数万分子消融，然后归因于物理假设失败。

# 19. 条件扩展：有诊断证据才增加模块

## 19.1 通道不足

当误差随 MTO 通道数增加稳定下降，且参数匹配基线不能解释时，可从 16 增至 32；或测试完整动态通道矩阵。不要因为 NTO 有多对就规定 MTO 通道数必须等于 NTO 对数。

## 19.2 汇总前二阶信息不足

若局部大幅抵消伴随特定张量任务失败，可加入

\[
L_a^{(0e,2e)}=\sum_i
[F_{ai}\otimes_{\mathrm{CG}}F_{ai}]^{(0e,2e)}
\]

等汇总前二阶分支。它保留了“一阶和为零但局部二阶结构非零”的信息，是数学上明确的候选增强。

同时给 B2 增加相同等级的二阶路径，以区分 MTO 组织的贡献与额外计算的贡献。该分支无优势时删除，不继续堆叠。

## 19.3 远程几何不足

如果实际 cutoff／消息路径导致片段间距离根本未被编码，仅增加全局加权求和不能恢复未知的距离。此时才比较显式距离相关的原子对分支或额外等变非局域消息。[R12]

原子对读出必须使用相对位置，并对交换对称和置换一致性进行审计。计算复杂度、参数和距离范围给所有基线公平处理。新增原子对路径有用，不自动说明它学到了正确电子相关。

## 19.4 不能通过添加的“物理正则”

不强制不同态 routing 正交，不强制 `Σ_i c=0`，不规定各通道电子占据，不用熵正则制造离域，不把两条任意 latent 分支叫作 electron 和 hole，不将完整振子强度求和规则强压在最低 K 态上。

真实波函数正交、跃迁密度积分为零与完整谱求和关系，并不直接转化为任意 latent 系数的相同约束。

摘要按“化学问题→MO 启发→几何输入与光谱监督→公平预测比较→独立诊断与结构检验→适用边界”组织。没有数据前，不在摘要写入改善百分比、发现数量或普适外推能力。

# 21. 成功、部分成功与失败后的处理

**完整支持。** 预测具有竞争力；至少一个预先定义的低数据／OOD 任务对强基线有实际优势；冻结 probe 和直接支持图的证据稳定；结构干预与至少一个前瞻性问题支持其化学用途。此时可以将其定位为经电子结构检验的 MO-inspired molecular representation。

**表示成功但直接图不稳定。** 保留“latent 中有可读出的激发空间信息”，不说 routing 就是电子分布。主文改以 probe、迁移和化学预测用途为主，降低 orbital-like visualization 的结论强度。

**预测成功但没有化学证据。** 定位为 spectroscopy readout／representation 方法。MO 仍可作为设计灵感，但不能把这等同于已证明 chemical insight。

**与 state token 等效。** 不宣称一种必要或独占的新表示。如果化学分析流程确有独立用途，可以将贡献放在可重复组织和分析协议；否则收缩研究主张。

**取消共享无优势。** 如实报告独立系数没有在当前数据上形成实用改善。不能以“真实 MO 不共享”为由忽略负结果；MO 类比没有证明统计学习中共享约束一定有害。

**仅在方法不可靠区域失败。** 先区分参考误差与模型误差，补充适用范围；不能仅凭错误标签责怪模型，也不能以参考方法为借口抹掉全部模型失败。

JACS 的目标意味着需要有吸引力的化学问题与有说服力的证据，而不是必须每个模块都成为新理论。任何方案都不能在实验前保证达到该目标。

# 22. 分阶段执行与预算优先级

## Phase A：启动审计与最小实现

完成数据审计、输入权限锁定、MTO 三层系数索引、旋转与置换测试、A 头或标量标签分支、32–128 分子过拟合。交付 E0、E1 和一份可重复运行配置。

## Phase B：QM9S pilot 与小型化学流程并行

使用约 1–2 万分子、5 态、2 seeds，跑 B0/B1/B2/B3/M。并行完成约 12 个母体的 Chem-dev 小试验，重点检查 NTO 约定、支持图、态追踪和数据存储，不将其当最终盲测。

若 M 明显劣于基线，先排查容量、训练与实现；不扩大全部数据计算。若只是 signed routing 或 M0 无用，可按消融收缩，不必推倒主问题。

## Phase C：冻结正式模型与主对照

公共验证集确定最终宽度、loss、K 和训练预算，保存配置 hash。再运行 10 态正式 benchmark、5-seed 主比较与学习曲线。基于 pilot 的筛选必须发生在正式测试前。

## Phase D：建立与打开正式化学验证

按预先声明的母体／骨架隔离建库。冻结诊断定义、probe 协议与主终点。先用 probe-train／val，最后打开 Chem-test；test 的结果只决定结论，不回流调整主模型。

## Phase E：前瞻性检验与投稿整合

冻结候选池与预测，再运行 QC，保留成功与失败。按实际支持的主张选择论文标题、主图和 SI。

## 算力分配建议

先完成主基线和独立化学证据，再考虑扩展公共数据库、完整动态矩阵、复杂原子对读出或更多张量阶数。不要用几十种架构的小幅 MAE 比较挤掉受控化学验证。

全部矩阵的运行数在 pilot 后根据单次训练成本登记。低数据曲线可以先使用 3 seeds 筛查，再将主终点补至 5 seeds；探索性与确认性结果须分开。

## 23.3 主模型伪代码

```python
# Pseudocode: shapes and data permissions are part of the interface.
H = backbone(Z, R, batch)                  # t -> [N_total, C_in[t], 2*l+1]
u = invariant_context(H)                 # no raw orientation components
g = molecular_invariant_summary(u, Z, batch)
M, assembly = {}, {}

for t in irreps:
    B = equivariant_channel_linear[t](H[t])   # [N_total, C_mto[t], 2*l+1]
    c_raw = router[t](u, g[batch], state_queries)
    # c_raw: [N_total, K+1, C_mto[t]], independent outputs for type/channel
    c = tanh(c_raw)
    F = c[..., None] * B[:, None, :, :]
    M[t] = scatter_sum(F, batch) / sqrt(N_ref)
    assembly[t] = F

z, q2 = equivariant_state_relation(M)
E_eV = positive_energy_head(z)

if label_mode == "tensor":
    C = symmetric_factor_head(z, q2)
    A = C @ transpose(C)
    strength = trace(A)
elif label_mode == "scalar":
    strength = nonnegative_strength_head(z)
    A = None
else:
    raise ValueError("Unsupported or unaudited label mode")

f = (2.0 / 3.0) * eV_to_Hartree(E_eV) * strength
spectrum = broaden(E_eV, f, fixed_energy_grid, sigma_eV)
# The training loss cannot access orbital/density/CT diagnostics.
```

# 24. 投稿前最后核对：一句话能否被证据支撑

| 拟写表述 | 必要条件 |
|---|---|
| “MO-inspired” | 组合思想、系数索引及与真实 MO 的区别清楚 |
| “state-resolved” | 同分子不同态的任务、诊断和索引规则明确 |
| “without orbital supervision” | 主模型输入／损失无轨道／密度标签；probe 与开发用途已披露 |
| “captures excitation delocalization” | 指标定义、混杂控制、独立测试和方法敏感性支持 |
| “interpretable atomic participation” | 实际组装项、直接图基线、稳定性与模型依赖检验支持 |
| “improves generalization” | 预定义 OOD、同权限基线、跨种子效应支持 |
| “phase-invariant tensor” | 限定实态相位，正确 A 构造与测试；不混同电磁 gauge |
| “helps molecular design” | 候选与规则在 QC 前冻结，等预算对照支持 |
| “recovers molecular orbitals” | 本项目当前设计不支持，不能使用 |
| “explains all molecular global properties” | 本项目当前实验范围不支持，不能使用 |

**最后的主张不应是“因为 MO 成功，所以 MTO 必然成功”。应当是“MO 的组合思想启发了一个明确的表示设计，而我们用独立的化学证据检验了它在哪里有用、为什么值得使用、以及何时不能这样解释”。**

## 项目最终原则

> **MO 提供组合灵感；对称性保证实现合法；光谱提供训练约束；独立电子结构分析定义 chemical insight；受控与前瞻性计算决定这些解释是否有用。**
>
> **不需要把 MTO 证明成真实 MO。需要把“它是什么、它额外提供了什么、哪些证据支持这些用途”说清楚并做出来。**

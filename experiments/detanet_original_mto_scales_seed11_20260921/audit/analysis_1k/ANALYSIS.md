# 1k 单种子 DetaNet / MTO 实验分析

本分析只读取本轮已保存的历史曲线、最佳验证 checkpoint 测试预测与指标，不新增训练、不改变协议。分析时 1k 两次训练及测试预测已完成，但正式 Markdown 报告先前因 ASCII 编码异常退出；UTF-8 补跑作业 1299743 仍在排队，没有 STAGE_COMPLETE，10k 尚未启动。这里的分析文件不是阶段完成标记。

数据为既有 800/100/100 训练/验证/测试划分，seed=11。两模型使用同一完整 DetaNet 骨干及共同骨干初始化、相同 240 点目标、训练 RMS=0.02456461297439198、相同打乱种子、Adam+AMSGrad、有效 batch=64、学习率调度与最大 1000 epochs/早停规则。没有 OOM 缩小批次。测试用 A 第958轮与 B 第79轮的 checkpoint，没有使用末轮 checkpoint 替代。

| 指标 | A 原版 DetaNet | B planned MTO |
|---|---:|---:|
| 测试 MSE，原始尺度 | 0.0002883033 | 0.0002586554 |
| 测试 MSE / 训练 RMS² | 0.4777819 | 0.4286489 |
| 测试 MAE | 0.00926062 | 0.00508280 |
| 平均余弦相似度 | 0.7660213 | 0.8362683 |
| 最佳验证归一化 MSE | 0.3443486 | 0.2848179 |
| 最佳 epoch | 958 | 79 |
| 实际 epochs | 1000 | 231 |
| 训练耗时，分钟 | 19.705 | 5.906 |

MTO 测试 MSE 降低10.28%，MAE降低45.11%，余弦相似度增加0.07025；最佳验证MSE降低17.29%。归一化MSE是用共同训练RMS²除原始MSE，两者不是独立证据。训练RMS并不使测试集零预测的归一化MSE必然等于1。

**训练动态。** A 第1轮训练/验证归一化MSE约5766.68/837.59，第100轮验证0.74561，第500轮0.38683，第958轮0.34435。A较晚才触发降学习率（774、913轮），直到预算结束仍缓慢改善。最佳轮训练损失约0.34124，与验证0.34435接近；曲线更符合当前协议下拟合/优化尚不足，不能据此断言模型容量不足或最终能力上限。

B第1轮训练/验证0.95808/0.54118，第25轮验证0.29306，第79轮最佳0.28482。79→231轮训练损失0.07004→0.02132，验证0.28482→0.31658；130与181轮降学习率后仍未刷新最佳，231轮满足共同早停规则。这是明显的过拟合趋势。训练损失是更新过程中累计的批次损失，不是对某个固定checkpoint重新计算的全训练集损失，训练/验证差距只作趋势解释。

同样骨干初始化不等于两个读出具有相同初始输出分布。A原版直接读出与B物理解码器的初始损失相差很大；两模型按原协议保留各自初始化，无临时输出缩放或调参。因此观察到的是这两套完整模型在指定协议下的性能，不能把优势全部因果归于张量轨道机制。

**逐分子分布。** 在100个测试分子中，B有68个MSE更低、99个MAE更低、73个余弦相似度更高。逐分子MSE中位数从0.000136532降至0.0000959921，降低29.69%。配对相对MSE改善的中位数是31.02%；这与“中位数MSE之比”及主指标“总体MSE改善10.28%”是不同统计量，不应互换。

两模型各自最差10个分子占总平方误差约50.21%与52.20%。ID4312单个分子的改善贡献了净MSE改善约48.8%；同时ID15757等样本有退步。多数分子上的改善与总体结果对少数困难样本的敏感性同时存在。没有删除异常值、重复采样或进行显著性检验。

**误差来自哪些光谱区间。** 以下是事后描述性分区，未用于训练、选checkpoint或调整报告主指标。

| 能量区间 eV | A 区间 MSE | B 区间 MSE | MTO 相对改善 |
|---|---:|---:|---:|
| [1.5,5) | 0.000110361 | 0.0000572159 | +48.16% |
| [5,8) | 0.000895930 | 0.000941666 | −5.10% |
| [8,10.5) | 0.0000862478 | 0.0000312802 | +63.73% |
| [10.5,13.5] | 0.0000566553 | 0.000000136790 | +99.76% |

高能尾部的百分比很大，是因为B在近零背景上的误差极小，不代表主吸收峰精度提高了99%。A有约36.96%的预测网格点为负，B没有负值；这些负值中很多位于本应接近零的背景。现有MTO解码器通过非负强度与高斯展宽形成平滑非负谱，这与其背景误差较小的现象一致。5–8 eV主误差区B整体反而略差。因此本轮较强的证据是更干净的背景、更低MAE和较好的整体形状；不能泛化为所有主峰更准。

附加检查：以240点谱的全局最大值定义主峰，A/B平均峰位绝对误差为0.42527/0.43079 eV，中位数均0.35146 eV，没有显示B改善。该简化指标不是逐峰匹配。用梯形积分计算全谱面积，A/B面积MAE为0.0230905/0.0284008（源强度单位×eV），B反而高23.00%，其平均面积偏差也更负。这进一步表明点对点MSE改善不等于峰位、峰强或总强度全面改善；谱面积不等同于已验证的物理振子强度。

**固定样例。** 未挑选样本，使用既定测试列表前四个ID。19441、43669、122349的B误差更小，但仍分别存在峰位/峰宽、峰高高估等问题。114196中两者都显著低估强主峰，B更差。99个样本MAE更低而仅68个MSE更低，与“普遍减少背景小误差，但部分主峰大误差仍存在”的解释一致。

**成本。** B本次总训练耗时比A少70.03%，主要由于较早达到最佳验证点并触发早停。按日志平均每epoch，A约1.18秒，B约1.53秒，所以不能将总耗时节省表述成每步计算更快。两作业在不同节点执行（g0030/g0044），这里不是受控硬件吞吐基准。统计的时间包括训练/验证及保存过程，不包括排队与前置短检查；到达最佳epoch的时间不能当作实际训练总成本。

**本轮支持的结论。** 在800个训练分子、seed=11、当前完整模型与共同训练协议下，planned MTO取得较低测试MSE/MAE、更高余弦相似度，并以较少实际训练轮数结束。它已有过拟合趋势，主误差区、主峰位置及总谱面积尚未显示一致优势。A的收敛较慢、背景噪声较强，是本次差异的重要组成部分。

这是一轮单种子、100个测试分子的初步结果，不构成跨种子稳定性、统计显著性、MTO各模块独立贡献或潜在激发态物理正确性的证据。240点目标经过统一插值，源谱展宽未知，MTO保持sigma=0.2 eV，既有历史测试划分也不是全新未见测试集。后续10k/full按原协议继续，可重点观察MTO验证差距是否收窄、A背景噪声是否减少、5–8 eV误差差距是否变化；本次分析没有增加训练或改动预算。
